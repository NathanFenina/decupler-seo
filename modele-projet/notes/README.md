# Notes — la boîte d'entrée humaine

Ce dossier est à vous : idées, retours du client, comptes rendus d'appel,
captures. Écrivez librement, depuis Obsidian ou n'importe quel éditeur.

Deux étiquettes suffisent pour que Claude agisse :

- `#a-traiter` : la routine du vendredi lit la note, la transforme en action
  sur la page de suivi (ou en ligne de `memoire/decisions.md` si c'est une
  décision), puis remplace l'étiquette par `#traite` avec un lien vers ce
  qu'elle a créé ;
- `#fait-client` : un fait donné par le client (chiffre, délai, prix,
  certification). Il ne part sur le site qu'après avoir été recopié, avec sa
  source et sa date, dans `memoire/faits.md`.

Le reste n'est jamais lu par les routines : rien ne part d'une note sans
étiquette.
